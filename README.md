# MICROC ContractFlow

Contract, Resource, Time & Financial Management System.

Planning calendar with bookings, PAD accounting, time/travel/expense reporting,
approval workflows, customer billing and subcontractor payment — built on the
same stack as Mitrandir (React + Vite frontend, ASP.NET Core + EF Core backend).

Start here: [docs/FUNCTIONAL_DESIGN.md](docs/FUNCTIONAL_DESIGN.md)
Progress tracking: [PHASES.md](PHASES.md)

Requirement underlag lives in OneDrive (`Planeringsprogram/Underlag`) and is
intentionally not committed — it references real commercial partners.
